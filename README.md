# uni-app Snippets by cocomikes

Zed snippets for [uni-app](https://uniapp.dcloud.net.cn/) development, based on the snippets from [`uni-app-snippets-vscode`](https://github.com/uni-helper/uni-app-snippets-vscode).

## Supported languages

- Vue and HTML
- CSS, Less, SCSS, Sass, and Stylus
- JavaScript and TypeScript
- JSON with Comments (`jsonc`, suitable for `pages.json`)

## Development installation

Use **Install Dev Extension** in Zed and select this directory:

```text
/Users/mikes/projects/Zed/extension/zed-uni-app-snippets
```

After installation, type a snippet prefix in a supported language file. The extension is snippet-only and contains no runtime code.
